# 콘텐츠 조사 방법

해외 팬이 좋아하는 작품을 먼저 찾는다. 그다음 한국과 해외의 촬영지 자료를 조사해 장면별 로케이션 투어로 만든다. 타깃 독자는 외국인이고 조사 자료는 한국어도 포함한다.

사용자가 뉴욕 여행 때 네이버 블로그에서 이터널 선샤인 투어를 찾았던 경험이 기준이다. Scene Korea에서도 팬이 좋아하는 작품과 직접 방문할 수 있는 장소를 연결한다.

## 1. 해외 커뮤니티에서 작품을 찾는다

조사 범위는 영미권·중화권·일본권·유럽이다. 한 작품이 네 권역 모두에서 인기가 있어야 하는 것은 아니다. 조사할 때 특정 권역만 반복해서 보지 않도록 범위를 나눠 찾는다.

| 권역 | 조사 방법 |
| --- | --- |
| 영미권 | 영어 커뮤니티의 한국 영화·드라마 추천, 팬 토론, 한국 여행 질문을 읽는다. |
| 중화권 | 간체·번체 작품명으로 커뮤니티의 작품 추천과 장면·촬영지 방문 관심을 찾는다. |
| 일본권 | 일본어 작품명으로 팬 커뮤니티의 감상, 추천, 성지순례 이야기를 찾는다. |
| 유럽 | 프랑스어·독일어·스페인어·이탈리아어로 현지 팬 커뮤니티를 조사하고 권역이 확인되는 영어 글도 함께 읽는다. |

반복해서 추천되는 작품과 팬들이 기억하는 장면을 기록한다. 이미 촬영지를 방문했거나 여행 일정에 넣으려는 글은 코스를 만들 때 우선 참고한다. 새 작품뿐 아니라 팬들이 계속 찾는 과거 작품도 후보에 넣는다.

이미 서비스에 있는 작품도 계속 조사한다. 기존 투어에 없는 장면·촬영지를 찾으면 가까운 지점을 기존 동선에 추가하거나 별도 스토리로 묶는다. 작품이 같다는 이유로 후보에서 제외하지 않는다.

영어로 작성됐다는 이유만으로 작성자를 영미권이나 유럽 거주자로 분류하지 않는다. 권역을 확인할 수 없으면 언어만 기록한다. 작품 선호, 촬영지 방문 관심, 실제 방문 경험은 구분하며 커뮤니티 글 몇 개를 국가별 인기 순위로 표현하지 않는다.

## 2. 작품명으로 촬영지와 방문 후기를 찾는다

작품을 고른 뒤 한국어·해외 배급 제목으로 투어, 로케이션, 촬영지, 유명 장면의 장소를 검색한다. 네이버·티스토리의 한국 블로그와 한국관광공사·지역 관광기관 자료, 외국 블로그를 함께 읽는다.

| 자료 | 찾을 내용 |
| --- | --- |
| 한국 블로그 | 직접 방문한 사진, 장면과 장소의 연결, 주소, 도보 동선, 교통과 방문 팁 |
| 한국관광공사·지역 관광기관·장소 운영자 | 촬영 사실과 장소명, 공식 주소, 공개된 방문 조건 |
| 외국 블로그 | 해외 팬의 방문 경험, 외국인이 헷갈린 교통·입장 정보, 원하는 사진 구도와 장면 |

검색어는 작품명에 `촬영지`, `성지순례`, `투어`, `filming locations`, `location tour`를 붙여 바꿔가며 찾는다. 블로그에서 발견한 장소는 관광 자료나 독립적인 방문 기록과 대조한다. 원문을 열 수 없으면 검색 결과의 요약만으로 촬영 사실을 확정하지 않는다.

장면이 실제 촬영된 곳인지 먼저 확인한다. 작품의 배경 설정, 촬영 스튜디오, 팬이 추천한 일반 관광지를 혼동하지 않는다. 정확한 회차나 대사를 확인하지 못했다면 추측해서 넣지 않는다.

## 3. 가까운 장면을 하루 코스로 묶는다

같은 작품의 촬영지를 지도에서 확인하고 가까운 장소끼리 묶는다. 이동·관람·사진 촬영·휴식을 포함해 최대 하루 안에 방문할 수 있도록 순서를 정한다. 먼 장소를 모두 한 코스에 넣지 않고 같은 작품에서도 여러 스토리를 만든다.

기생충의 ‘취업이 시작된 동네’와 ‘폭우 속 귀갓길’처럼 장면의 흐름으로 코스를 구분한다. 각 장소에는 어떤 장면에 나왔는지와 팬이 그곳에서 무엇을 볼 수 있는지를 설명한다. 촬영지 사이에 넣은 식사·휴식 장소는 촬영 장소와 구분한다.

코스 시작점까지의 광역 이동은 현지 투어 시간과 따로 안내한다. 현재 출입·영업 여부와 이동 수단을 확인하고 외관만 볼 수 있는 장소는 그렇게 적는다. 새로 찾은 장소가 기존 투어와 겹치면 장면이나 동선을 보강할 수 있는지 먼저 살펴본다.

기존 작품을 확장할 때는 등록된 장면·장소·방문 순서와 비교한다. 기존 이야기와 자연스럽게 이어지고 하루 안에 방문할 수 있으면 해당 투어를 보강한다. 다른 인물의 이야기나 멀리 떨어진 촬영지라면 같은 작품의 별도 투어로 만든다.

## 4. 근거와 투어 콘텐츠를 남긴다

| 기록 | 남길 내용 |
| --- | --- |
| 작품을 고른 근거 | 작품명, 조사 권역과 언어, 커뮤니티 글 URL, 게시일과 확인일, 확인한 팬 반응 |
| 장면과 장소의 근거 | 장면 설명, 장소명과 주소, 블로그·관광 자료 URL, 확인일과 방문 조건 |
| 투어 구성 | 스토리 제목, 방문 순서, 이동 방법과 예상 시간, Google Maps·NAVER Map 링크 |

투어 제목과 설명은 영어로 작성한다. 작품명·장면·장소가 드러나는 고유 SEO 제목과 설명을 투어마다 만든다. 중국어·일본어 자료를 조사하는 것과 서비스의 화면·검색 언어를 추가하는 것은 별개다.

이미지는 실제 장면 스틸과 현장 사진을 구분하고 출처와 이용 조건을 기록한다. 조사 출처는 내부 문서와 데이터에 보존한다. 화면의 `Scene reference` 링크는 다시 추가하지 않는다.
