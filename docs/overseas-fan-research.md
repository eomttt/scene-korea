# 해외 팬 조사와 스토리 투어 확장

확인일: 2026-09-24

기존 50개에 20개를 더해 작품 61편의 스토리 투어 70개를 구성했다. 한국 영화 8개, 드라마·시리즈 56개, 해외 영화의 한국 촬영지 6개다. 방문지는 총 139개다.

팬의 실제 방문·여행 의향·작품 추천을 구분했다. 공개 글은 개별 사례이며 국가별 인기 순위나 현재 시장 규모를 뜻하지 않는다. 예전 방문기의 촬영 장면은 참고하되 당시 요금·영업시간·실내 출입 조건은 현재 정보로 재사용하지 않았다.

## 코스 구성 기준

한 작품 안에서 장면을 묶는다. 멀리 떨어진 촬영지는 같은 작품의 다른 스토리로 분리했다. 어벤져스의 세빛섬과 상암, 블랙 팬서의 자갈치와 광안리는 각각 따로 방문한다.

한 장소에서 여러 장면을 떠올릴 수 있는 짧은 방문도 허용한다. 주변 산책이나 식사 장소를 별도 촬영지로 세지 않았다. 첫 장소까지의 장거리 이동은 현지 소요 시간과 구분했다.

초원사진관은 복원 세트로 표시했다. 학교·교회·업무용 건물은 허용된 외관만 안내하며 선로·차량기지·사유지는 방문 동선에서 제외했다. 겨울연가의 철거된 집과 학교 담장은 넣지 않았다.

장성향은 실제 장면 촬영 근거를 확인했다. 현재 파는 만두가 촬영 당시 같은 레시피였다는 주장은 하지 않는다. [가게 주인 인터뷰](https://www.kookje.co.kr/news2011/asp/newsbody.asp?code=1600&key=20220127.22013006854)

## 검색과 자료 관리

작품명·스토리·장면·장소 검색에 작품 분류와 소요 시간 필터를 결합했다. 소요 시간은 범위의 최댓값으로 비교한다. 32편에 별칭을 제공하며 일본어·중국어 공식 표기도 포함한다. 같은 작품의 여러 스토리가 함께 검색된다.

화면의 Scene reference 링크는 제거했다. 촬영 근거는 routes.json의 source와 sources에 보존한다. 사진 출처와 라이선스 표시는 유지하며 추가한 20장까지 docs/image-sources.json에 기록했다. 공개 사진을 찾은 것과 상업적 이용 허가를 받은 것은 구분한다.

투어 70개 모두 제목·설명·canonical·공유 이미지·구조화 데이터를 제공한다. 사이트맵은 일반 페이지 3개를 포함해 73개 URL이다.
